# Supabase setup

For a fresh project run, in order:

1. `01_schema.sql`
2. `02_seed.sql`
3. `04_full_sales_upgrade.sql`
4. Create an Auth user, then edit and run `03_make_admin.sql` to grant admin access.

If `01_schema.sql` and `02_seed.sql` are already installed, run only `04_full_sales_upgrade.sql` now.
