# Monterra Residence v2 — что сделать после загрузки в GitHub

## 1. Сначала обнови Supabase

В Supabase открой **SQL Editor → New query** и целиком запусти:

`supabase/04_full_sales_upgrade.sql`

Этот файл:
- создаёт реальные места парковки и кладовки как отдельный инвентарь;
- добавляет их в конфигуратор цены;
- добавляет `selected_inventory` и `inventory_total` в заявки;
- создаёт RLS-политики для нового инвентаря;
- оставляет только Smart Home и отделку в обычных пакетах;
- добавляет ещё одну запись хода строительства.

Файл безопасно запускать повторно.

## 2. Загрузи обновлённый код в тот же GitHub-репозиторий

В корне репозитория должны остаться `app`, `components`, `lib`, `public`, `supabase`, `package.json` и остальные файлы.

После commit в `main` Vercel автоматически создаст новый deployment. Переменные Supabase повторно добавлять не нужно.

## 3. Что проверить на сайте

- `/` — интерактивный дом теперь показывает реальные статусы квартир из Supabase.
- `/mieszkania` — фильтры + три вида: карточки, список, 2D-планы.
- `/mieszkania/<slug>` — 2D / интерактивный 3D / виртуальный spacer.
- В конфигураторе выбрать конкретное парковочное место, кладовку, Smart Home и пакет отделки — итоговая цена должна пересчитываться.
- Отправить тестовую заявку — она должна появиться в таблице `leads` вместе с `selected_inventory`.

## 4. Админка

Для `/admin` всё ещё нужен пользователь Supabase Auth и запись в `admin_profiles`.
Если это ещё не сделано:
1. Supabase → Authentication → Users → Add user.
2. Скопируй UUID пользователя.
3. В `supabase/03_make_admin.sql` замени `PASTE_AUTH_USER_UUID_HERE` на UUID и запусти SQL.
4. Войди на `/admin/login`.

В панели v2 можно:
- менять цену, статус и публикацию квартиры;
- менять статус заявок;
- менять цены и статусы парковок/кладовок;
- менять цены пакетов отделки и Smart Home;
- добавлять обновления хода строительства;
- видеть KPI и историю изменений цены.
